## 技术栈

- Vite 6 + Vue 3（`<script setup>`）+ vue-router（history 模式）
- 样式：原生 CSS + 设计 token（`src/styles/tokens.css`），**不引 UI 框架、不用 Tailwind**
- 无状态管理库（数据静态，composable 足够）
- 数据为构建期打包的 JSON（`src/data/*.json`）
- 自评进度存 `localStorage`，不联网、不上传

## 设计说明

视觉方向取自题材本身——试卷与答题卡的物质语言，而不是通用落地页模板：

- **色彩**：墨蓝黑 `#141C26`（试卷油墨）／冷白纸 `#F7F7F4`／批改红 `#C8342B`／密封线靛 `#3A5A8C`／铅笔灰 `#61686F`
- **字体**：标题与题头用中文衬线（Songti SC / SimSun / Noto Serif CJK SC，走系统字体栈，不引 CDN 字体）；正文用系统黑体；考期、分值、题号用等宽
- **签名元素**：首页左侧**竖排密封线**（`密封线内不要答题`）；掌握度自评做成**答题卡涂格**（涂满＝熟／半涂＝模糊／空框红叉＝不会）；考期索引是**答题卡式密表**
- **印章**只用在「预测题」页——圆形「模拟卷 · 非真题」章，语义正确（标记非官方）
- **可访问性**：正文对比度达 WCAG AA；保留键盘焦点样式；`prefers-reduced-motion` 下关闭动效；语义化标签与 `aria-pressed`

## 数据来源与免责
